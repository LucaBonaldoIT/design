# Changelog

## 0.1.0 — 2026-10-08

First release, extracted from lucabonaldo.dev.

- Palette and role tokens, light and dark, plus the `.ds-inverse` surface.
- Base element styles, and components: text helpers, buttons, form fields, panels, tags,
  notices, dialog, header with theme toggle, footer and credit, reveal.
- Self-hosted Fraunces and Inter.
- Theme controller with a cookie shared across `*.lucabonaldo.dev`, and a Vite plugin that
  inlines the no-flash init script.
- Favicon frame and the lucabonaldo.dev icon.
- Specimen page in `docs/`.
