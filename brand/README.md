# Brand assets

- `favicon-template.svg`: the app icon frame. Every app uses the same tile (64×64, `rx=14`,
  vermilion `#b02e0c` on an ink `#1a1712` rim) with its own cream (`#fff7f0`) glyph.
- `favicon-lb.svg`: the lucabonaldo.dev icon, built on that frame.

Glyphs are drawn as paths, not `<text>`, so they render the same without the fonts.
